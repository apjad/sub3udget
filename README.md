# Sub3udget shared catalog

`subscriptions.json` is a plain data file fetched by the Sub3udget iOS app's "Vælg fra liste"
picker. Prices are typical/approximate Danish market defaults — the app lets you adjust the
price and billing cycle after picking an entry, before adding it to your own list.

`domain` is used to fetch each service's logo via a public favicon service — no logo images are
hosted in this repo.
